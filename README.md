# stock-lstm-vs-persistence

Does an LSTM beat `tomorrow's close = today's close` at next-day stock price prediction?

Fifteen large-cap tech tickers, daily bars from December 2020, evaluated in dollars against a
persistence baseline on a held-out period the models never saw during training or selection.

> **Scaffold — results not yet published.** This README is replaced once the experiments run.

## What this is not

A trading system, a price forecast, or investment advice. It is a forecasting-methodology
study: the point is the comparison against a trivial baseline, not the predictions.
